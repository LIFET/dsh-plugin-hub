写一个 dsh 插件Write a dsh plugin

dsh 的插件系统建立在 Cordis 之上：一个插件就是一个拿到上下文、往里注册能力、卸载时收回的模块。下面是社区常走的路子。The dsh plugin system is built on Cordis: a plugin is a module that takes a context, registers capabilities into it, and cleans up on unload. Here's the path the community takes.

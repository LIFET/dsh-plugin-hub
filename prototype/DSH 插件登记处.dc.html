来源机制

插件不由本站评审，也不由本站分发。收录只走一条公开链路，任何人都能自己走一遍、自己核对。

01
作者打上话题

官方 README 要求的唯一登记动作：给插件仓库加上 dsh-plugin 话题。

topics/dsh-plugin ↗
02
按话题抓取

抓取器按话题拉取仓库元数据：名称、描述、许可、最近提交时间。不读代码，不执行任何东西。

03
人工精选归类

向社区精选名单提 PR，一个插件一行描述，落到七个分类里的一个。

awesome-dsh-plugin ↗
04
带出处展示

目录里每一行都能展开出处链，回溯到上游名单的那一行。展示层不改写、不排名。

NOTE

收录不等于背书。插件在你的机器上以完整权限运行，安装前请自行阅读仓库源码与许可。dsh 仍处于开发者预览阶段，官方明确会有破坏性变更，部分插件可能已经跟不上当前版本。

如何被收录

不需要向本站申请。走完公开链路，下一次快照就会带上你的插件。

01 给仓库加上 dsh-plugin 话题，写清描述与许可。
02 在精选名单里提一个 PR，中英两份 README 各加一行。
03 合并后等下一次快照。出处链会指回你那一行。

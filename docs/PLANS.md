# 自托管迁移计划

## 目标

将项目从 Cloudflare Workers、KV 与 Cron 迁移为单机可运行的 Next.js Node.js 服务，并部署到 `apiu.cc`。

## 影响范围

- 运行时：vinext/Workers 改为 Next.js Standalone。
- 数据：KV 改为服务器本地 JSON，采用进程锁与原子替换。
- 调度：Cloudflare Cron 改为 systemd timer。
- 网关：复用现有 Nginx、HTTPS 和 `127.0.0.1:18200`。
- 保持不变：页面、公开数据结构、插件发现和安全筛查规则。

## 风险

- Node.js 必须满足 `>=22.13.0`，使用项目专用运行时，避免影响其他服务。
- 同步写入必须防止重入和半写文件。
- 同步接口必须仅允许持有 `CRON_SECRET` 的本机任务调用，公网由 Nginx 返回 404。
- 发布前必须完成构建、Lint、测试和本地 Smoke；服务器切换后验证其他站点。

## 实施顺序

1. 替换构建与启动依赖。
2. 迁移注册表持久化和 API。
3. 增加受保护同步入口与 systemd 单元。
4. 更新测试并完成本地验收。
5. 在独立 release 目录构建，原子切换服务。
6. 验证 HTTPS、公开 API、定时器和其他站点。

# 全站体验与稳定性优化（2026-08-15）

## 目标

修复巡检闭环、安装放行、移动端导航、详情可访问性、真实路由、目录扩展性、SEO 与重复数据传输，不改变自托管架构。

## 影响范围

- 巡检：永久错误退避、匿名限额保护、手动批量回填。
- 安全：仅源码检查为 `clear` 的插件生成安装命令。
- 页面：真实 URL、可分享详情、URL 筛选、每批 36 条。
- 体验：移动端底部导航、焦点锁定、复制反馈、仓库预检、巡检进度。
- 性能：移除外部字体、注册表进程缓存、API ETag、取消重复客户端请求。

## 验收

Build、Lint、20 项测试、移动端真实浏览器、键盘焦点、仓库预检与 Lighthouse 全部通过后才允许部署；当前阶段保持未部署。
